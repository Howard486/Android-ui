# iOS 風格桌面 + 三情境（Focus 模型）

承 `HOME_REDESIGN.md`。這份記錄「把桌面改成 iOS 觀感，情境疊在上面」的決定與作法。

## 核心衝突與解法

iOS 桌面的承諾是「東西永遠在你放的地方」。原本的 Space 模型承諾相反：桌面依情境重排。
兩者直接疊加會做出看起來像 iOS、行為不像的東西。

而且原本的實作已經在付代價：`home_items` 以 `(spaceKey, postureKey, …)` 為鍵，
**三個模式各有一份完全獨立的排列**。在通用擺好的 app，在工作模式裡不存在。

解法採 iOS 16 Focus 的模型：

> **一份排列。情境只決定「顯示哪幾頁」、哪個 Dock、通知策略、主題。**

實作上引入 `HomeSurface`，取代 `SpaceId` 作為排列的鍵：

| Surface   | 誰在用        | 內容                     |
|-----------|---------------|--------------------------|
| `Desktop` | 通用、工作    | 共用的分頁排列           |
| `Simple`  | 簡易          | 固定四格 + 大時鐘        |

簡易仍然是獨立的一塊，因為它本來就不是「桌面的一種檢視」，而是另一個版面。

頁面的可見性存在 `home_pages.contexts`：逗號分隔的情境 key，空字串 = 所有情境都顯示。
最左頁（通用→新聞、工作→工項）不入儲存索引，維持 `HOME_REDESIGN.md` 的既有決定。

## iOS 化清單

依「視覺回報 ÷ 工時」排序。

1. **圖示 squircle 化** — 最大的一項。原本 `AppIcon` 把 drawable 原樣畫進方形，
   完全沒有遮罩：adaptive icon 連背景整塊露出、legacy icon 各帶各的形狀，
   一頁看起來就是雜的。iOS 的整齊感絕大部分來自這裡。
   - adaptive icon：依 108/72 的安全區重繪前景/背景，再用超橢圓遮罩。
   - legacy icon：內縮後墊在同一塊 squircle 底色上，取得一致外框。
2. **Dock** — `Dock.kt` 早就寫好，但只有 Tabletop / Book / 充電座在用，
   主分頁桌面根本沒有。補上並讓它固定在每一頁下方。
3. **App 資料庫**（最右頁）— 沿用既有的 `AppCategorizer` 13 個分類。
   關鍵差別：這是**檢視**，不是重排。一鍵分類原本會真的搬動桌面，
   所以才需要 undo；改成資料庫頁之後風險歸零。
4. **Jiggle mode** — 長按進編輯，圖示微幅擺動 + 左上 ✕。受 `MotionLevel` 節制，
   省電或降動態時不擺動。
5. **格線可調** — 預設 4×6（iOS 原味），另有 5×6、5×7。變更會重排桌面，
   設定頁明講。

## 做不到 / 不做

- **SF Pro 不能用**：Apple 專有字體。若要換字，metric 最接近的免費選項是 Inter。
- **不複製 Apple 的圖示美術**：做 iOS 風格的視覺語言，用我們自己的素材。
- **毛玻璃需要 API 31**（`RenderEffect.createBlurEffect`），minSdk 是 30，要判斷。
- **下滑手勢衝突**：iOS 下滑是搜尋，目前下滑是叫出系統通知欄。維持現狀，
  搜尋留在上滑；兩個都綁下滑只會互搶。
